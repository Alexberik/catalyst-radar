# CATALYST RADAR

24–48h market anomaly scanner — crypto (live) + equities (watchlist), real-style charts, **paper trading demo with $100**.

**Live:** https://alexberik.github.io/catalyst-radar/

## What this is
- Radar of high-activity assets (volume / impulse / simple risk score)
- Lightweight Charts for the selected ticker
- Demo portfolio: start with **$100 virtual USD**, buy/sell from the radar
- Honest positioning: **not** investment advice, **not** a promise of x100 returns

## What this is not
- Not a broker
- Not guaranteed signals
- Not a substitute for your own risk management

## Data
- **Crypto:** CoinGecko public markets API (live)
- **Equities:** curated watchlist with light demo dynamics (wire a real equities API key for production)

## Stack
Static site for GitHub Pages: HTML / CSS / JS  
Design system: Dovetail-style command center (near-black, soft indigo `#6798ff`, Inter + JetBrains Mono, blueprint grid)

## Local
Open `index.html` via any static server, or push to `main` and enable GitHub Pages.
