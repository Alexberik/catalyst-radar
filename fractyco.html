06 / AI IMAGE ANALYSIS (OPTIONAL)

Подключить полноценный AI-анализ

Для понимания графиков, таблиц и мелких подписей нужен vision-модельный backend. GitHub Pages — статический хостинг: секретный API-ключ нельзя безопасно хранить в HTML. Вставь URL своего защищённого backend, который принимает JSON с изображениями и возвращает текстовый анализ. Не вставляй сюда API-ключ.

Не подключено. Без backend работает локальное OCR-распознавание.

Ожидаемый контракт backend: POST JSON { images: [{name, mimeType, dataUrl}], prompt: string } → JSON { analysis: string }. Backend должен сам вызывать vision-модель и не логировать изображения/секреты. Это поле не отправляет скриншоты автоматически: внешний AI-вызов выполняется только после явного нажатия отдельной кнопки анализа, которая появится при успешном подключении.
